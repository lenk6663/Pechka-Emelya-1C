# Pechka Emelya 1C

Исходные файлы конфигурации проекта для работы в 1C:Enterprise Development Tools (EDT) находятся в папке `ПечкаЕмеля`.

- `ПечкаЕмеля/.project` — описание проекта EDT.
- `ПечкаЕмеля/src` — исходные файлы метаданных конфигурации.
- `ПечкаЕмеля/DT-INF` — служебное описание EDT-проекта.

Изменения конфигурации следует вносить в проект EDT и сохранять в Git вместе с файлами исходной конфигурации.
